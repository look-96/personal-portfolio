# Personal Portfolio

A responsive, static portfolio site built with HTML, CSS, and vanilla JavaScript. The stylesheet uses a British racing green palette.

## Included features

- Semantic page structure and keyboard-accessible navigation
- Responsive project cards and skills list
- Project category filters
- Keyboard-operable image lightboxes
- Client-side contact form validation
- Reduced-motion support and visible keyboard focus styles

## Personalize before sharing

1. Replace `[Your Name]`, role, introduction, skills, and year in `index.html`.
2. Replace the example project titles, descriptions, categories, and GitHub links.
3. Replace `images/project-one.svg` and `images/project-two.svg` with screenshots, and update their `alt` text.
4. Connect the contact form to a form service or backend. It currently validates fields but does not send messages.

## Preview locally

Open `index.html` in a browser. The page uses only relative file references, so the HTML, CSS, JavaScript, and images should stay in this folder structure.

## Publish with GitHub Pages

Push the contents of this folder to the root of a GitHub repository. In the repository's Pages settings, select the `main` branch and `/ (root)` as the publishing source. The published page will use the `index.html` file at the repository root.
